# ConvertIt Backend API Specification

This document defines the HTTP API contract for the ConvertIt backend service. All endpoints are prefixed with `/api`. Responses are serialized as JSON unless streaming media or binary attachments.

---

## Headers & Global Conventions

- **`X-Request-Id`**: Attached to every incoming and outgoing response. If not provided by client, generated by server.
- **`X-Access-Code`**: Required on all routes except `/api/health` and `/api/limits` when `ACCESS_CODE` is enabled on the server.
- **Security Headers**: All responses include `X-Content-Type-Options: nosniff`. Job snapshot and download endpoints include `Cache-Control: no-store`.

---

## Error Envelope

When an error occurs, the server responds with a standardized error object:

```json
{
  "error": {
    "code": "VIDEO_TOO_LONG",
    "message": "The requested video duration exceeds the 60-minute limit.",
    "retryable": false,
    "retryAfterSec": null,
    "details": {}
  }
}
```

### Common Error Codes

| Code | HTTP | Meaning | Retryable |
|---|---|---|---|
| `AUTH_REQUIRED` | 401 | Missing or invalid `X-Access-Code` | No |
| `INVALID_URL` | 400 | Malformed or non-YouTube URL | No |
| `UNSUPPORTED_URL` | 400 | Channel, playlist, or unsupported host | No |
| `FILE_TOO_LARGE` | 413 | Uploaded payload exceeds `MAX_UPLOAD_MB` | No |
| `UNSUPPORTED_FILE_TYPE` | 415 | File extension or magic bytes not permitted | No |
| `FILE_CORRUPT` | 422 | Empty (0-byte) or corrupted file payload | No |
| `INVALID_OPTIONS` | 422 | Malformed tool options JSON | No |
| `NO_TABLES_FOUND` | 422 | PDF to Excel found no tables (scanned PDFs need OCR) | No |
| `JOB_NOT_FOUND` | 404 | Job ID not found or already deleted | No |
| `JOB_EXPIRED` | 410 | Result file exceeded TTL (default 15m) | No |
| `RATE_LIMITED` | 429 | Exceeded per-minute requests or active jobs | Yes (`Retry-After`) |
| `QUEUE_FULL` | 503 | Global queue capacity reached (default 20) | Yes (`Retry-After`) |
| `SERVER_BUSY` | 503 | Server disk full or server draining for shutdown | Yes (`Retry-After`) |
| `CONVERSION_TIMEOUT` | 504 | Job exceeded maximum allowed duration | No |
| `INTERNAL` | 500 | Unhandled internal exception (returns requestId) | Yes |

## Endpoints

### 1. `GET /api/health`

Public operational health status. Does not touch third-party upstreams or YouTube.

**Response `200 OK`**:
```json
{
  "status": "ok",
  "version": "0.2.0",
  "uptimeSec": 420,
  "ytdlpVersion": "2025.01.26",
  "queue": {
    "running": 1,
    "queued": 0
  }
}
```

---

### 2. `GET /api/limits`

Public server configuration and limits. Allows frontend to reflect actual server quotas.

**Response `200 OK`**:
```json
{
  "maxUploadMB": 25,
  "ytMaxDurationMin": 60,
  "ytMaxFilesizeMB": 300,
  "ytMaxHeight": 1080,
  "accessCodeRequired": false,
  "youtubeEnabled": true,
  "concurrency": {
    "heavy": 1,
    "youtube": 2,
    "light": 2
  },
  "maxQueueLength": 20
}
```

---

### 3. `POST /api/jobs/convert`

Ingests multipart form uploads for server-side processing. Streams data directly to disk without buffering in RAM.

**Request (`multipart/form-data`)**:
- `toolId` (string, required): Registered tool ID (e.g. `echo-convert`, `pdf-to-word`)
- `options` (string, optional): JSON-encoded options object (defaults to `{}`). The web app adds `format` with the chosen output (for example `"csv"` for `pdf-to-excel`). `pdf-to-excel` also reads `mode`: `"lattice"` (ruling lines, default) or `"stream"` (whitespace-separated columns).
- `file` (binary file, required): Raw file payload

**Response `202 Accepted`**:
```json
{
  "jobId": "q6yX-pL_9aBk87zM2sK4wQ"
}
```

---

### 4. `GET /api/jobs/{id}`

Retrieves the current state and progress snapshot of a job.

**Response `200 OK`**:
```json
{
  "id": "q6yX-pL_9aBk87zM2sK4wQ",
  "type": "convert",
  "toolId": "echo-convert",
  "status": "succeeded",
  "stage": null,
  "progress": 100,
  "queuePosition": 0,
  "createdAt": "2026-02-19T06:00:00Z",
  "startedAt": "2026-02-19T06:00:01Z",
  "finishedAt": "2026-02-19T06:00:03Z",
  "error": null,
  "result": {
    "filename": "converted_report.txt",
    "sizeBytes": 1024,
    "mime": "text/plain",
    "expiresAt": "2026-02-19T06:15:03Z"
  }
}
```

---

### 5. `GET /api/jobs/{id}/events`

Server-Sent Events (SSE) stream pushing real-time progress and lifecycle transitions.

**Headers**:
- `Accept: text/event-stream`

**Stream Events**:
- `event: status` -> Initial state or state change (`queued`, `running`, `cancelled`)
- `event: progress` -> Progress updates (`{"progress": 45, "stage": "converting"}`)
- `event: done` -> Terminal success (`{"result": {...}}`)
- `event: error` -> Terminal error (`{"error": {...}}`)
- `: ping` -> 15-second heartbeat comments to keep firewalls and proxies alive

---

### 6. `DELETE /api/jobs/{id}`

Cancels a queued or running job, terminates external subprocess groups, and deletes ephemeral job files.

**Response `200 OK`**:
```json
{
  "status": "cancelled"
}
```

---

### 7. `GET /api/jobs/{id}/download`

Streams the completed converted file. Schedules directory deletion 60 seconds after the initial complete download.

**Response `200 OK`**:
- Headers:
  - `Content-Disposition: attachment; filename="<sanitized-filename>"`
  - `Cache-Control: no-store`
  - `X-Content-Type-Options: nosniff`
- Body: Binary stream

### 8. `POST /api/chat`

Streams a Google Gemini answer grounded in page-numbered excerpts. The browser extracts and searches the PDF locally. Send JSON with `Accept: text/event-stream` and the usual access-code header when enabled.

```json
{
  "question": "What marks the mountain trail?",
  "chunks": [{"page": 10, "text": "Blue triangles mark the mountain trail."}],
  "history": []
}
```

| Field | Contract |
|---|---|
| `question` | String, 1–2,000 characters |
| `chunks` | 1–8 objects, each with an integer page ≥1 and 1–1,500 characters of text |
| `history` | Optional list of up to six messages in chronological order. Each contains a `user` or `assistant` role and up to 4,000 characters of content. |

Unknown fields and invalid types or limits return HTTP 422 with `INVALID_OPTIONS`. The API applies the standard access, job creation, per-IP, and queue limits. Each stream holds one light-job slot until completion or disconnect. Chat payloads and answers stay out of job records and logs.

```text
event: token
data: {"token":"Blue triangles "}

event: token
data: {"token":"[p. 10]"}

event: done
data: {}

```

The client concatenates token strings. Closing the connection cancels the provider request. A provider failure before streaming returns the JSON error envelope. A failure during streaming ends with an `error` event containing the same envelope. The server sets a 60-second provider I/O timeout and a 90-second overall deadline.

| Condition | HTTP | Error code |
|---|---|---|
| Missing provider key | 503 | `PROVIDER_NOT_CONFIGURED` |
| Provider rejected the key, authentication or access (Gemini sends bad keys as HTTP 400) | 502 | `PROVIDER_AUTH_ERROR` |
| Configured model does not exist (`GEMINI_MODEL`) | 502 | `PROVIDER_MODEL_NOT_FOUND` |
| Provider not available from the server's region | 502 | `PROVIDER_UNAVAILABLE` |
| Provider rejected the request for another reason | 502 | `PROVIDER_BAD_REQUEST` |
| Provider daily quota or token limit exhausted | 429 | `PROVIDER_QUOTA_EXHAUSTED` |
| Provider rate limit | 429 | `PROVIDER_RATE_LIMITED`, with a 30-second retry hint |
| Provider timeout | 504 | `PROVIDER_TIMEOUT` |
| Other provider failure | 502 | `UPSTREAM_ERROR` |

Every provider failure is logged as `chat_provider_error` with the provider's HTTP status, error type, message (first 500 characters) and the model name. The question, excerpts and answer are never logged.
